# netcs-study


This repository corresponds to the results and scripts of experimental evaluations of NetCS.

The NetCS method, which reconstruct blobs of degree 5 or more, producing a semi-directed level-1 network from gene trees, was introduced in this paper:

Dai and Molloy, 2026, Is level-1 blob reconstruction under the network multispecies coalescent easy?, bioRxiv(Accepted to WABI 2026); doi: https://doi.org/10.64898/2026.06.06.730607
