This directory contains the data products and experimental results used
for the CAMUS simulation analysis in the NetCS study.

The CAMUS data set consists of simulated level-1 phylogenetic networks
that are used to evaluate end-to-end network reconstruction and the
estimation of the underlying tree of blobs (TOB).

THe CAMUS data set can be downloaded from [Dataset for "CAMUS: Scalable Phylogenetic Network Estimation"](https://databank.illinois.edu/datasets/IDB-6892704)

After extracting all zipped file, the deposited files are organized so that the different stages of the
analysis can be examined independently:
